# BondMemo Documentation
Welcome to BondMemo - a private relationship memory tool for friends and family.

These inherited and updated guides document development and self-hosting for BondMemo. BondMemo is based on Monica 4.x; upstream-specific pages and historical commands may still use the Monica name.
